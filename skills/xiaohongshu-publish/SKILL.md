# 小红书智能发布助手

这个 skill 是一个智能化的小红书内容发布工具，支持多种内容形式，并提供专业的爆款优化建议。

## 核心功能

### 1. 多格式内容支持

#### 📹 视频发布
- 支持上传视频文件（MP4、MOV 等格式）
- 自动识别视频时长和尺寸
- 支持添加封面图
- 标题限制：25字以内

#### 🖼️ 图文发布（两种模式）

**模式A：图片上传**
- 支持上传 1-9 张图片
- 支持 JPG、PNG 格式
- 建议尺寸：3:4 竖版或 1:1 方图
- 标题限制：25字以内
- 正文限制：1000字以内

**模式B：文字配图**
- 自动将文字生成精美配图
- 单图文字限制：500字以内
- 支持多图拼接（最多9张）
- 自动排版和美化
- 标题限制：25字以内

#### 📝 长文发布
- 标题限制：64字以内
- 正文支持：万字长文
- 一键智能排版
- 自动段落优化
- 支持添加分段标题

### 2. 智能内容识别

自动判断用户提供的内容类型：
- 检测是否包含视频文件 → 视频发布
- 检测是否有图片 + 文字较少 → 图文发布（图片上传）
- 检测纯文字且字数 500 字以内 → 图文发布（文字配图）
- 检测长文内容 → 长文发布

### 3. 爆款优化引擎

#### 🎯 标题优化建议
- 分析内容主题，生成 3-5 个爆款标题方案
- 运用小红书热门标题公式：
  - 数字型：「3个方法」「5分钟学会」
  - 疑问型：「为什么...」「你知道吗」
  - 情绪型：「太绝了」「YYDS」「必看」
  - 悬念型：「原来...」「没想到」
- 合理使用 emoji 增加吸引力
- 控制在字数限制内（图文25字/长文64字）

#### 📋 内容格式优化
- **段落优化**：自动分段，提高可读性
- **排版美化**：添加适当的空行和符号
- **重点标注**：关键信息用 emoji 或符号突出
- **结构建议**：
  - 开头：引人入胜的钩子
  - 中间：有价值的干货内容
  - 结尾：引导互动（点赞、收藏、关注）

#### 🏷️ 官方话题推荐
- 根据内容分析推荐官方热门话题
- 优先选择有流量扶持的话题
- 话题分类：
  - 垂直领域话题（美妆、穿搭、美食、旅行等）
  - 热点话题（节日、热点事件）
  - 长期话题（日常、生活、分享）
- 建议 3-5 个话题，不超过 10 个
- 提供话题热度和竞争度参考

#### 💡 互动优化建议
- 提供互动引导语建议
- 评论区预设问题（提高互动率）
- 发布时间建议（根据内容类型推荐最佳发布时段）

## 技术实现要点

### 内容类型判断逻辑

```python
def detect_content_type(user_input):
    """
    智能判断内容类型
    """
    # 检测视频文件
    if has_video_file(user_input):
        return "video"

    # 检测图片
    if has_image_files(user_input):
        text_length = get_text_length(user_input)
        if text_length <= 1000:
            return "image_post"  # 图文（图片上传）

    # 检测纯文字
    text_length = get_text_length(user_input)
    if text_length <= 500:
        return "text_to_image"  # 图文（文字配图）
    elif text_length > 1000:
        return "long_article"  # 长文
    else:
        return "image_post"  # 默认图文
```

### 爆款标题生成算法

```python
def generate_viral_titles(content, content_type):
    """
    生成爆款标题
    """
    max_length = 25 if content_type != "long_article" else 64

    # 1. 分析内容主题和关键词
    keywords = extract_keywords(content)
    theme = analyze_theme(content)

    # 2. 应用标题公式
    templates = get_title_templates(theme, content_type)

    # 3. 生成多个候选标题
    titles = []
    for template in templates:
        title = fill_template(template, keywords)
        if len(title) <= max_length:
            titles.append({
                "title": title,
                "type": template.type,
                "score": calculate_viral_score(title)
            })

    # 4. 按爆款指数排序，返回前5个
    return sorted(titles, key=lambda x: x['score'], reverse=True)[:5]
```

### 官方话题匹配

```python
def recommend_official_topics(content):
    """
    推荐官方话题
    """
    # 1. 内容分词和主题分析
    keywords = extract_keywords(content)
    category = classify_content(content)

    # 2. 从话题库中匹配
    topics = []

    # 垂直领域话题（3-4个）
    vertical_topics = match_vertical_topics(category, keywords)
    topics.extend(vertical_topics[:4])

    # 通用话题（1-2个）
    general_topics = get_general_topics()
    topics.extend(general_topics[:2])

    # 热点话题（0-1个）
    if has_trending_keywords(keywords):
        trending = get_trending_topics(keywords)
        topics.extend(trending[:1])

    # 3. 返回话题及热度信息
    return [{
        "topic": topic,
        "heat": get_topic_heat(topic),
        "competition": get_topic_competition(topic)
    } for topic in topics[:5]]
```

### 一键排版功能

```python
def auto_format_content(content, content_type):
    """
    智能排版
    """
    # 1. 段落分割
    paragraphs = split_paragraphs(content)

    # 2. 优化每个段落
    formatted = []
    for para in paragraphs:
        # 控制段落长度（2-4行）
        if len(para) > 200:
            para = split_long_paragraph(para)

        # 添加适当的 emoji
        para = add_contextual_emoji(para)

        # 重点内容标注
        para = highlight_key_points(para)

        formatted.append(para)

    # 3. 添加结构元素
    if content_type == "long_article":
        # 长文添加小标题
        formatted = add_subheadings(formatted)
        formatted = add_dividers(formatted)

    # 4. 组合并添加空行
    return "\n\n".join(formatted)
```

## 注意事项

### ⚠️ 平台规范
- 严格遵守小红书社区规范
- 避免违禁词和敏感内容
- 不发布广告、引流等违规内容
- 尊重原创，不抄袭

### 🔒 账号安全
- 首次使用需手动登录
- 建议使用已登录的浏览器 session
- 避免频繁自动化发布（建议间隔 > 30分钟）
- 不在公共环境使用

### 📏 内容限制
- **视频**: 时长 < 5分钟，大小 < 1GB
- **图片**: JPG/PNG，每张 < 20MB，1-9张
- **标题**: 图文≤25字，长文≤64字
- **正文**: 图文≤1000字，长文无限制
- **文字配图**: 单图≤500字

### 🎯 爆款建议
- 前3秒/前3行是关键，必须吸引眼球
- 话题标签 3-5 个最佳，不超过 10 个
- 合理使用 emoji，但不要过度（< 10%）
- 保持真实和接地气，避免浮夸
- 引导互动，但不要强求（不要"求点赞"）

### 🛠️ 技术要点
- 需要 Playwright MCP 支持
- 首次运行可能需要安装浏览器
- 网络不稳定时会自动重试（最多3次）
- 遇到验证码会暂停等待人工处理
- 页面元素变化时会自动适配

## 错误处理

```
1. 登录失败
   → 提示用户手动登录
   → 等待登录完成信号

2. 上传失败
   → 检查文件格式和大小
   → 重试上传（最多3次）
   → 提供错误原因

3. 内容审核不通过
   → 分析可能的敏感词
   → 提供修改建议
   → 重新发布

4. 网络超时
   → 自动重试
   → 超过3次后询问用户

5. 页面元素找不到
   → 截图当前页面
   → 分析页面结构变化
   → 提示用户并记录日志
```
